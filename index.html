KSTAR · status pageсторінка статусів

A bookmarklet that opens a compact status page for a KSTAR hybrid inverter on top of the KSTAR Sync portal: grid state and outage history, battery runtime, BMS data, energy balance and browser alerts. Works while you are logged in to sync.ksdatacloud.com.

Закладка відкриває компактну сторінку статусів гібридного інвертора KSTAR поверх порталу KSTAR Sync: стан мережі й історія відключень, запас батареї, дані BMS, енергобаланс і сповіщення в браузері. Працює, коли ви залогінені на sync.ksdatacloud.com.

Desktop (Chrome, Edge)

Комп'ютер (Chrome, Edge)

  1. Show the bookmarks bar: Ctrl+Shift+B.
  2. Drag this button to the bookmarks bar:
    ⚡ KSTAR status
  3. Open sync.ksdatacloud.com, log in and click the bookmark. The status page opens in a new tab. To open a specific station, click the bookmark while on that station's page.
  1. Увімкніть панель закладок: Ctrl+Shift+B.
  2. Перетягніть цю кнопку на панель закладок:
    ⚡ KSTAR статус
  3. Відкрийте sync.ksdatacloud.com, увійдіть і натисніть закладку. Статуси відкриються в новій вкладці. Щоб відкрити конкретну станцію, натисніть закладку на сторінці цієї станції.

Android (Chrome)

  1. Copy the code below.
  2. Bookmark any page (☆), then edit the bookmark: name it kstar and paste the code into the URL field.
  3. Open the KSTAR portal, type kstar in the address bar and pick the bookmark from the list (the one with the star icon).
  1. Скопіюйте код нижче.
  2. Додайте будь-яку сторінку в закладки (☆), потім відредагуйте закладку: назва kstar, у полі адреси вставте скопійований код.
  3. Відкрийте портал KSTAR, у адресному рядку наберіть kstar і виберіть закладку зі списку (з іконкою зірочки).

What the page shows

Що показує сторінка

  • Grid on/off with the exact time of the last change, taken from the inverter alarm log
  • SoC and estimated runtime down to the off-grid discharge limit read from the inverter
  • Outage statistics for 7/14/28 days: a timeline per day and how often each hour is without grid
  • Daily chart of SoC, load and grid import with exact outages and short grid drops; grid voltage quality
  • Per-module BMS data: SOH, cycles, capacity, cell voltage spread and temperatures
  • System self-consumption: battery DC minus inverter AC during outages, plus daily energy balance
  • Live mode (portal Quick Update, ~10 s), firmware update check, browser alerts with sound
  • Є чи немає мережі і точний час останньої зміни, за журналом тривог інвертора
  • SoC і запас роботи до межі розряду без мережі, прочитаної з інвертора
  • Статистика відключень за 7/14/28 днів: смуги по днях і як часто немає світла в кожну годину
  • Графік за добу: SoC, навантаження, імпорт, точні відключення й короткі провали; якість напруги мережі
  • Дані BMS по модулях: SOH, цикли, ємність, розкид напруги комірок, температури
  • Власні потреби системи: DC батареї мінус AC інвертора під час відключень і добовий енергобаланс
  • Живий режим (Quick Update порталу, ~10 с), перевірка оновлень прошивки, сповіщення зі звуком

The bookmarklet only loads the latest version of the page from this repository, so there is no need to reinstall it after updates. It does not store or send your password or token: the page uses the portal session already open in your browser, and data flows only between your browser and sync.ksdatacloud.com. Source code and API notes: github.com/vlgook/kstar-status.

Закладка лише підтягує свіжу версію сторінки з цього репозиторію, тож після оновлень коду перевстановлювати її не треба. Вона не зберігає і не передає пароль чи токен: сторінка використовує сесію порталу, відкриту у вашому браузері, і дані йдуть лише між браузером і sync.ksdatacloud.com.
